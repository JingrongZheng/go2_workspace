## Approach

按 `docs/navigation/real-deployment.md` 的 R3 阶段协议，建立纯 3D MCL 重定位入口（Point-LIO 机体 IMU + `mapping_cloud.py` + `lego_loam_bor/mcl_feature` + `dddmr_pg_map_server_node` + `mcl_3dl`，不启动规划器与任何 `/cmd_vel` 控制节点）。先在无网络隔离容器内，加载 EXP-0034 调平地图 `experiments/EXP-0034/optimized-map-201812-v2`，回放真实录包 `.work/sessions/bag-20261125-201833` 前 45 秒，并故意向 `/initial_3d_pose` 发布偏离真实起点约 `(+0.48 m, -0.35 m, +11.5°)` 的粗初始位姿，验证粒子滤波收敛、TF 责任分离与零控制发布。

## Notes

未修改作者只读源码；离线验证在无网络容器内执行，未连接实机或发送控制指令。

## Results

- 新增共享文件：
  - `shared/dddmr/real/config/l2_localization_lab.yaml`（L2 96×360 投影、`use_sim_time: false`、`ground_frame: base_footprint`、`num_particles: 80`）
  - `shared/dddmr/real/go2_live_localization.launch.py` 与 `shared/dddmr/real/run_live_localization.sh`（单 Docker 启动，自动保存 `stack.log`）
  - `shared/dddmr/real/go2_localization.rviz`（将标准 `2D Pose Estimate` 工具直接绑定到 `/initial_3d_pose`，宿主机 RViz2 点一下即可给粗位姿，同时叠加显示已保存地图、红色实时雷达扫描、黄色粒子云与 TF）
  - `./go2` 新增 `./go2 localize <SAVED_MAP_DIR> [SESSION_DIR] [GROUND_Z]` 与 `./go2 rviz localize`。
- 45 秒离线 R3 重定位验证结果（`experiments/EXP-0035/r3-offline-check/r3-summary.json`）：
  - 话题计数：`/odom` 579、`/laser_cloud_sharp` 575、`/ground_cloud` 576、`/mcl_pose` 71、`/particles` 72；`/cmd_vel` 发布者数为 **0**；
  - 粗初始位姿收敛：`/mcl_pose` 方差 `var_xyz` 从初始 `[1.8373, 1.6132, 0.0275]` 迅速收敛到 **`[0.0328, 0.0142, 0.0078]`**（标准差约 `18 cm × 12 cm × 8.8 cm`），并稳定跟踪机器人沿房间行进至 `map→base_link = [4.188, -0.013, 0.121]`；
  - TF 责任清晰：`map→odom = [-0.414, 0.037, 0.256]`（由 `mcl_3dl` 唯一发布），`odom→base_link = [4.604, -0.053, -0.062]`（由 Point-LIO 唯一发布）。

## Conclusion

R3 离线重定位链路（从原始传感器录包到 3D MCL 在调平地图上的粗位姿收敛与连续跟踪）已通过验证，且已封装为可直接现场使用的 `./go2 localize` 与 `./go2 rviz localize`。此为离线回放验证，实机现场 R3（新上电任意位置人工给粗位姿 + 手动小范围走动）待用户在现场执行验收。
