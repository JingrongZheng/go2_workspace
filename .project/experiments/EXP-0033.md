## Approach

记录用户完成的 392.4 秒全房间闭环扫描（`.work/sessions/live-20261125-201812` 与配套原始录包 `.work/sessions/bag-20261125-201833`）的精确路程与起终点偏移指标；随后以独立配置 `experiments/EXP-0033/l2-mapping-loop-h30.yaml`（`enable_loop_closure: true`、`history_keyframe_search_num: 30`）在无网络容器内离线回放 `bag-20261125-201833`，验证回环闭合能否消除 `+0.742 m` 的 Z 轴漂移。

## Notes

未修改作者只读源码与默认 `l2_mapping_lab.yaml`；未连接实机或发送控制指令。

## Results

### 1. 现场闭环扫描基线（未开回环）
详见 `experiments/EXP-0033/baseline-live-201812-metrics.json` 与 `baseline-preview.png`：
- 录包时长：`392.36 s`（6045 帧点云，全程零锁死、零断流）；
- 关键帧 / 累计路程：**`318` 关键帧** / **`55.55 m`**；
- 地图规模：`ground.pcd` 17,024 点、`map.pcd` 1,494 点；
- 起终点位置：起点 `[-0.281, -0.001, -0.001]`，终点 `[-0.400, -0.153, +0.741]`；
- 起终点闭合偏移：**XY `0.193 m`**（0.35%）、**Z `+0.742 m`**、**3D `0.767 m`**。

### 2. 离线在线回环测试（`history_keyframe_search_num=30`）
- 增大历史窗口至 30 后，DDDMR **成功触发并建立了多条高精度回环边**（如 `221→101` ICP `0.01`、`225→103` ICP `0.00`、`246→145` ICP `0.04`、`256→149` ICP `0.01`、`258→150` ICP `0.02`），证明 L2 点云在 `history_keyframe_search_num=30` 下具备可靠的回环配准能力；
- 但在第 258 关键帧连续每秒插入回环边后，`lego_loam-9` 发生段错误退出（`exit code -11`），未能运行至保存阶段（`mapping_cloud.py` 仍完整跑完 6045 帧输入）。根因为上游 `lego_loam_node` 中 1 Hz `loopClosureThread` 与 1 ms `run()` 在不同回调组并发访问共享状态（`isam`、`gtSAMgraph`、`recentCornerCloudKeyFrames`）。

## Conclusion

55.55 米实机闭环基线已完整记录；同时证实了：（1）`history_keyframe_search_num=30` 可以让 L2 稀疏点云成功建立高精度回环边；（2）上游在线 `lego_loam_node` 在高频并发回环下存在段错误风险，默认配置继续保持 `enable_loop_closure: false` 是必要的。后续应采用离线同步位姿图优化（如对已保存的 318 关键帧地图直接做离线回环闭合优化）来安全消除 `+0.742 m` 的 Z 轴漂移。
