## Approach

使用 EXP-0024 第二轮真实 WiFi 录包 motion-trial-02，在单个无网络容器中运行 Point-LIO 的 L2点云＋完整机体IMU配置，再向 DDDMR 提供当前传感器扫描和 `/odom`。仅运行作者建图节点、适配器及地图保存/重载验证；没有规划器、运动控制桥、Gazebo或模型真值。

验收为：地面与特征持续发布、关键帧增长、保存完整pose graph、作者地图服务器可读并响应首末关键帧查询。本实验不包含完整实验室扫描或导航验收。

## Notes

继续前已读取 PLAN-0003 执行计划及 EXP-0024。独立 reviewer 因 Linux 项目写保护能力不可用，以下为本机自检和实际运行证据，不称为独立审查。

核对源代码确认：仿真Go2配置是16×440、±15°、机械旋转扫描时间模型；DDDMR对安装roll/yaw有特殊转换，不直接套用到当前固件发布坐标。Point-LIO与DDDMR还同名发布aft_mapped_to_init，必须隔离。源代码只读保留，没有修改仿真启动或参数。

## Results

### 坐标、时间与点云适配

- 新增 mapping_cloud.py，使用已有实测 publishedCloud→base 变换、真实逐点time及Point-LIO `/odom` 轨迹进行去畸变。
- 在 odom 中累积3帧，转换到最新扫描结束时的 `dddmr_lidar`。其轴与base_link平行，原点与固件发布点云一致；不是世界累计地图，也不再次套用物理radar安装角。
- 下游DDD自身拼接设1，scan_period设0以关闭按旋转角臆测逐点时间的旧模型。实际约15.42Hz及逐点time仍由适配器使用。
- 输出DD优化里程计重映射到 `/dddmr/aft_mapped_to_init`；Point-LIO的 `/aft_mapped_to_init`、机体 `/odom` 保持独立。DDDMR仅发布map→odom，不重复发布外部odom→base_link。

### 首轮实机参数

| 参数 | 值 | 依据 |
|---|---:|---|
| ground_z，相对base_link | −0.31686765 m | 本次初始25帧地面拟合7340个内点，残差中位6.16mm，不从40cm机身高度猜测 |
| 投影网格 | 96×360 | 虚拟角度栅格，不代表硬件有96线 |
| 垂直角域 | −90°～90° | 适配后的机体轴向扫描 |
| 补偿累积 | 3帧 | 非重复扫描覆盖，历史点经过运动补偿 |
| 输入量程 | 0.1～20 m | 实验室首轮 |
| 地面候选俯仰 | −90°～约−1.72° | 全方位朝下候选 |
| 地面跨环补点距离 | 0.3 m | 不沿用原1m；关闭首环到机体盲区填补 |
| 关键帧距离/角度 | 0.15m / 0.15rad | 原仿真1m/1rad不适合本次短路线 |
| 地面可视化体素 | 0.15m | 原仿真0.4m |
| 回环 | 关闭 | 首轮隔离验证；回环待更大范围数据 |

四处Cuboid仍用已约定EDU 1.1倍尺寸0.770×0.341×0.440m，底面使用同一ground_z。建图不运行相应规划器，不能把Cuboid当作地面补全参数。参数快照 l2-mapping-v1.yaml 与共享 config/l2_mapping_lab.yaml 数值一致。

### 保存及重载

- 首轮接收1191帧适配点云和1191帧地面输出，生成24关键帧。保存成功，含 map.pcd、ground.pcd、poses.pcd、edges.pcd 和24×3个逐帧 feature/surface/ground PCD，共76个PCD。
- 保存全局特征图162点、地面2241点、位姿24点；map.pcd是作者的稀疏特征图，不是稠密墙面地图。逐帧表面数据另存，不能仅复制map.pcd。
- 整理后的共享 run_mapping_replay.sh 再次完整执行通过，输出 experiments/EXP-0025/replay-final/maps/2026_11_25_07_39_27。与首轮的点数/关键帧数一致，但部分点序/浮点数据非逐字节相同；两份资产分别进行了作者服务器重载。
- 最终地图由作者 dddmr_pg_map_server 载入：24位姿、102个聚合特征点、354个聚合表面点、2256个聚合地面点，首帧与第23帧的服务查询均可返回内容。服务器再次降采样，点数不等于保存文件的点数。
- 首轮地面拟合在DDDMR map坐标中约2.11°，残差中位1.07cm、95分位5.55cm。map的初始坐标与Point-LIO odom不是同一个原点/姿态，不能直接比较绝对坐标当作漂移；后续扩大扫描要核查整体地面、墙体重影和回环。
