## Approach

针对多终端长命令分散以及文档/配置中存在 `/home/suiliang/go2_workspace` 硬编码的问题，在不改动已验证的 Point-LIO / DDDMR 算法与参数前提下，以 `go2_workspace` 为可迁移单位统一入口并清理路径与外部耦合。

## Notes

本轮仅涉及共享启动封装、可迁移性整理与文档更新，未连接实机、未启动硬件采集或发送任何控制请求。当前环境未找到 `project-infra` CLI 与 `.work/infra-runtime.md`，已按项目 schema 同步更新 `.project/` 记录。

## Results

- 新增工作区根目录可执行入口 `go2`（`./go2`），动态基于自身路径推导 `ROOT`，统一收口 `ssh`、`relay`、`map`、`rviz`、`record`、`save-map`、`keyboard`、`replay`、`help` 子命令，支持 `wired`/`wifi` 模式自动匹配默认 IP 与 socket，支持 `GO2_*` 环境变量覆盖。
- 改造 `shared/connect_go2_ssh.sh`，支持 `[wired|wifi] [--host IP] [--user USER] [--socket PATH] [--close]`，直连 `unitree@<IP>`，不再依赖宿主机 `~/.ssh/config` 的 `unitree_go2` 别名。
- 将 `experiments/EXP-0002/keyboard_control.py` 沉淀为 `shared/go2_keyboard_control.py`，更新 `shared/go2_wifi_keyboard.py` 与 `shared/run_webrtc_keyboard.sh` 引用，解除共享脚本对历史实验目录的耦合。
- 清除 `shared/dddmr/real/README.md`、`shared/go2_wifi_keyboard.md`、`shared/dddmr/README.md`、`docs/navigation/dddmr-download.md`、`docs/navigation/sources.json` 中全部 `/home/suiliang/go2_workspace` 硬编码路径，并在 `shared/dddmr/real/README.md` 顶部置顶 `./go2` 速查流程，同步更新 `TOOLKIT.md`。
