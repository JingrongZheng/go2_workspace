## Approach

1. **方案对齐**：核查 `Tsukimisaka/MamboTTS`（本地 GPT-SoVITS 模型）与讯飞开放平台接口边界，按用户“需要实时合成、不走离线模型”的需求，采用 **讯飞「一句话复刻」实时 WebSocket 流式合成（`wss://cn-huabei-1.xf-yun.com/v1/private/voice_clone`，`vcn=x5_clone`）+ Go2 WebRTC 扬声器播报**。
2. **共享代码收口（`shared/audio/`，独立于导航栈）**：
   - `shared/audio/xfyun_tts.py`：PyAV 音视频提取转讯飞训练规范 WAV（单声道 24 kHz 16-bit PCM ≤ 3 MB）、讯飞 HMAC-SHA256 鉴权、一句话复刻/标准 TTS 流式 PCM 合成、本地别名映射（`.work/xfyun_voices.json`）及针对 `clone` 引擎默认开启的首字重复补偿（解决实测稳定的首字丢失现象）。
   - `shared/audio/xfyun_clone_train.py` + `run_clone_train.sh`（入口 `./go2 voice-train`）：封装讯飞 `aiauth/v1/token`、`voice_train/task/traintext`、`task/add`、`task/submitWithAudio`（纯 Python RFC 7578 multipart + MD5 签名）与 `task/result` 轮询，支持自动对齐服务端 UTC 时钟。
   - `shared/audio/go2_audio_play.py` + `run_audio_play.sh`（入口 `./go2 speak`）：复用 `.work/webrtc-venv` 与 `.work/webrtc-system-libs`（PortAudio），支持 `--test-tone`、`--file`、`--text`、`--interactive`、`--local-preview` 及 Go2 三种播音通道（`stream` WebRTC 48 kHz 实时音轨边合成边播、`megaphone` 分片喊话、`audiohub` 上传按 UUID 播报并清理）与可选 VUI 音量设置（`api_id=1003`）。
3. **凭证与安全隔离**：API 凭证仅存于被 `.gitignore` 忽略的 `.work/xfyun.env`（权限 `600`）与 `.work/xfyun_voices.json`，不提交任何密钥；全程不发送任何运动控制指令。

## Notes

- 讯飞 `voice_clone` 接口返回 `res_id` 不可自行缩短改名，改名会导致服务端检索失败；通过在本地 `.work/xfyun_voices.json` 建立短别名（`mambo` / `man` / `teenager`）兼顾易用性与协议兼容。
- 实测发现讯飞 `x5_clone` 合成首句存在稳定的首字丢失现象（输入“正在测试...”需输入“正正在测试...”才能完整发出“正”），已在 `xfyun_tts.py` 的 `preprocess_tts_text()` 默认开启首字自动重复补偿（可通过 `--no-dup-first-char` 关闭）。
- `--transport stream` 为真实边合成边播（每收到讯飞 PCM 分片即重采样推入 WebRTC 48 kHz `AudioStreamTrack`）；`--local-preview` / `megaphone` / `audiohub` 当前为收完全部分片拼 WAV 后播放。
