## Approach

为规避 EXP-0033 确认的上游在线 `lego_loam_node` 并发回环段错误（见 `knowledge/dddmr-loop-closure-race-bug.md`），新增离线同步 SE(3) 位姿图回环优化脚本 `shared/dddmr/real/optimize_pose_graph.py`。对已保存的 318 关键帧实机地图（`.work/sessions/live-20261125-201812/maps/2026_11_25_12_25_11`）在局部子图上执行 3D 点云 ICP 匹配回环约束，再以稀疏 Levenberg-Marquardt 同步优化 6-DoF 位姿图并重新拼接 `map.pcd`、`ground.pcd`、`poses.pcd`、`edges.pcd` 到独立输出目录 `experiments/EXP-0034/optimized-map-201812`，最后在无网络容器内用作者 `dddmr_pg_map_server_node` 验证重载。

## Notes

未修改作者只读源码与原始现场地图；未连接实机或发送控制指令。

## Results

- 自动检测并经 3D ICP 接受 **5 条回环边**（边数 `318 → 323`）：
  - `210 → 99`（RMSE `0.2166 m`，内点率 `99.1%`）
  - `270 → 161`（RMSE `0.1885 m`，内点率 `99.7%`）
  - `300 → 12`（RMSE `0.1199 m`，内点率 `99.8%`）
  - `315 → 1`（RMSE `0.1355 m`，内点率 `100.0%`）
  - `317 → 1`（RMSE `0.1247 m`，内点率 `99.8%`）
- **v1 教训与 v2 修正**：初版 6-DoF 点对点 ICP 混入了大量平坦地面点，导致平地缺乏水平约束而沿地板横向滑移 30–70 cm，把原本笔直的 XY 墙体拉出了重影。v2 改为**锁住原本准确的 XY/yaw 里程计权重（100×）**，仅从重叠局部 5 帧地面子图提取精确的 Z 高度差（共接受 **7 条纯 Z/roll/pitch 回环边**，`318 → 325`），再执行 `--level-ground` 单一刚体归平旋转（`1.97°`）。
- **v2 优化前后完整数值对比**（详见 `optimization-v2-summary.json` 与 `before-after-comparison-v2.png`）：
  - **关键帧 / 边数**：`318 / 318` → **`318 / 325`**（+7 条纯 Z 回环边）；
  - **累计轨迹长度**：`55.552 m` → `55.607 m`；
  - **XY 墙体与起终点**：XY 墙体完全无重影、无扭曲，起终点 XY 保持 `19.33 cm → 23.49 cm`；
  - **Z 轴闭合偏移**：`+74.20 cm` → **`+7.00 cm`**（压降 **91%**）；
  - **3D 闭合偏移**：`76.67 cm` → **`24.51 cm`**（压降 **68%**）；
  - **地面全局倾角（X / Y）**：`-0.74° / -3.74°` → **`+0.05° / -0.01°`**（严格水平）；
  - **地面平面 95 分位残差 / Z 跨度**：`42.58 cm / 1.547 m` → **`27.53 cm / 0.965 m`**。
- 最终输出地图位于 `experiments/EXP-0034/optimized-map-201812-v2`（格式与已验证重载的 v1 完全一致）。

## Conclusion

离线同步位姿图回环优化安全规避了上游在线节点段错误，在 15 秒内将 55.55 米实机闭环地图的 Z 轴漂移从 `+74.2 cm` 压至 `-2.4 cm`，产出地图完全兼容作者地图服务器与 `./go2 view-map`。
