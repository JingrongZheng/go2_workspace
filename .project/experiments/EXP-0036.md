## Approach

按用户预期将 R3（3D MCL 重定位）与 R4（A\* 全局规划、P2P 局部规划、3D Cuboid、L2 局部障碍感知与 `/cmd_vel` 只读预检）合并为一个单 Docker 干跑入口（`./go2 nav-dryrun` + `./go2 rviz nav`），不启动任何真机速度桥。相对上游仿真 `go2_localization.yaml`，将 `perception_3d_local` 与 `perception_3d_global` 激光视野改为 L2 适配（±60° 垂直、360° 水平、`marking_minimum_height: 0.08 m` 以检出桌下 10–25 cm 低矮障碍），Cuboid 统一为 EDU 1.1×（`0.770×0.341×0.440 m`），速度限幅为 `max_vel_x: 0.35 m/s`、`max_vel_theta: 0.8 rad/s`。在无网络 Docker 中回放 `bag-20261125-201833` + `optimized-map-201812-v2` 并发送 `/initial_3d_pose` 与 `/goal_pose_3d` 验证全链路。
