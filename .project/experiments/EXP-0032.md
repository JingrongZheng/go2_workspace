## Approach

新增 `shared/dddmr/real/run_view_map.sh`、`shared/dddmr/real/go2_view_map.rviz` 与 `./go2 view-map` 子命令，用于 3D 交互查看保存地图的完整图层；同时用独立配置文件 `experiments/EXP-0032/l2-mapping-loop.yaml`（仅将 `enable_loop_closure` 改为 `true`）在无网络容器内离线回放 `.work/sessions/bag-20261125-190540`，评估回环闭合能否消除 Z 轴漂移。

## Notes

未改动默认配置 `shared/dddmr/real/config/l2_mapping_lab.yaml` 中的 `enable_loop_closure: false`；未连接实机或发送控制指令。

## Results

- 新增 `./go2 view-map <SAVED_MAP_DIR> [--server-only]`：自动在 Docker 启动 `dddmr_pg_map_server_node` 并打开宿主机 RViz2，显示 `/map1/mapground`、`/map1/mapsurface`、`/map1/mapcloud`、`/map1/key_poses`（Transient Local + Reliable），关闭 RViz 时自动清理容器。
- 离线回环对照回放结果（`experiments/EXP-0032/replay-190540-loop`）：
  - 全程 232 关键帧、232 条边（与 EXP-0031 一致，**未新增回环边**，末端 Z 仍为 `0.333 m`）；
  - `stack.log` 给出明确原因：`Too clustered! In range: 5..15 points, overall: 5..15 points. Distance between two frame is higher than 1.0 m, ignore loop closure.`
  - 即该录包末端 `(-0.67, 3.90)` 距离起点 `(-0.28, 0.00)` 仍有约 3.9 m（大于 1.0 m），且默认 `history_keyframe_search_num=5` 对稀疏 L2 点云而言在 1.0 m ICP 体素降采样后仅剩 5–15 点，被作者的聚类保护直接忽略。

## Verification

- `bash -n go2 shared/dddmr/real/run_view_map.sh` 与 `./go2 help` 通过。
- `./go2 replay .work/sessions/bag-20261125-190540 experiments/EXP-0032/replay-190540-loop -0.3168676504844956 experiments/EXP-0032/l2-mapping-loop.yaml` 退出码 0。

## Conclusion

`./go2 view-map` 已可用；仅简单开启 `enable_loop_closure: true` 不会在未走回起点 1m 内且 `history_keyframe_search_num=5` 的稀疏 L2 录包上触发回环，保持默认配置 `enable_loop_closure: false` 不盲目开启。
